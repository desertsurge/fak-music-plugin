# 扩展使用说明

本文说明当前发布候选版开发样例的使用方式和边界。`public/presets-fallback.json` 当前只保留已在 Edge 中实测可播放的 I LOVE RADIO 和 Jazz Radio；开放授权单曲和远程目录仍需完成真实可用性、许可证和归属审核。

## 安装

1. 执行 `npm install` 和 `npm run build`。
2. 在 Chrome 或 Edge 打开扩展管理页。
3. 打开开发者模式，选择“加载已解压的扩展”。
4. 选择项目下的 `dist/` 目录。

## 本地开发试听

执行 `npm run dev` 后打开 `http://localhost:5173/`，同一局域网设备可使用运行机器的 IP（例如 `http://192.168.23.47:5173/`）访问。开发页使用本地 `HTMLAudioElement` 适配器，点击电台卡片即可试听真实直播流；加载速度取决于电台连接，首次进入可播放状态可能需要几秒。关闭开发页不会保留播放，持续后台播放请加载 `dist/` 扩展。

## 播放

- 打开工具栏中的 Fak Music 图标。
- 在“推荐”中直接选择一项，或切换到“电台”“单曲”“收藏”视图。
- 使用搜索框按名称、艺术家或风格筛选。
- 点击搜索框右侧的筛选按钮，打开“全部/电台/单曲”类型筛选菜单；类型筛选会与当前视图和搜索条件组合生效。
- 使用卡片上的心形按钮收藏内容。
- 底部控制条提供播放/暂停、上一项、下一项和音量控制。

播放地址按以下顺序恢复：当前条目的主地址、该条目的备用地址、队列中的下一项。一个条目的所有候选地址失败后会自动跳过；如果队列中没有可用条目，底部状态显示“播放失败”。此状态下可使用播放/下一项控制重新尝试队列。本文不把 placeholder 地址的实际音频连通性视为已验证。

## 目录初始化与更新

扩展初始化时先读取内置快照或上一次缓存，确保 Popup 可以立即展示。Service Worker 随后从 `https://desertsurge.github.io/fak-music-plugin/presets.json` 刷新远程目录，也可在构建时通过 `VITE_CATALOG_URL` 覆盖为其他 HTTP(S) 地址；刷新不阻塞首屏。右上角显示“已同步”时代表当前目录来自远程数据；显示“本地目录”时代表正在使用内置或缓存数据。后台还会按 6 小时周期刷新。

远程请求只有在 HTTP 响应和目录格式校验均成功时才会替换当前目录。请求失败、超时、HTTP 错误或格式错误都会保留最后一次有效的 fallback/cache，不会清空现有卡片。点击右上角的“更新目录”可以手动刷新；失败时会显示错误和“重试”按钮，重试仍使用当前目录。

## 权限说明

- `storage`：保存目录缓存、收藏和音量。
- `alarms`：每 6 小时触发一次目录更新。
- `offscreen`：在 Popup 关闭后继续持有音频播放上下文。
- HTTP/HTTPS 主机权限：访问公开目录和目录中分布在动态域名下的第三方音频流。扩展不包含网页内容脚本，不读取或修改普通网页内容。

## 已知限制

- 电台内容由电台运营方提供，可能包含广告、主持节目或临时停播。
- 自动目录依赖 GitHub Pages 和 Radio Browser；二者不可用时会继续使用最后一次有效缓存或内置 fallback。
- 单曲必须带许可证和来源链接才能进入目录，但字段存在不等于本项目拥有第三方音频版权；还需遵守原作者归属、地区和在线播放条款。
- 项目尚未指定正式许可证，浏览器扩展商店发布前仍需补充 `LICENSE`、图标、隐私说明和商店材料。
- 本轮没有验证示例地址的真实音频播放，也没有验证扩展商店提交或发布。
